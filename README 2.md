# yolandegouws.com

Static portfolio site. No build step: Netlify publishes this folder as-is.

- `index.html`: Work overview (grid)
- `about.html`: About
- `work/*.html`: one page per artwork
- `img/<work>/`: web-sized images (`01.jpg` is the first image; `cover.jpg` is the grid thumbnail)
- `style.css`: all styling (frame, fonts, layout)
